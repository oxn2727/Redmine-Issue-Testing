## 十、F10 列表视图 · 过滤器 / 排序 / 自定义列（14 条）★重点

**统一前置**：`C1 + C2(reporter1) + C3`，且列表里已有 ≥ 5 条**不同状态 / 优先级 / 指派 / 类别**的 Issue；F10-08 需先用接口预置 1 条私有 Issue（本环境新建页无 Private 复选框）

### 10.1 过滤器怎么测 —— 分两件事，不套"全参 / 一参"

> **过滤器是"查询功能"，不是"入参接口"**，所以不套正向 3 类 / 反向 3 类那套。它测两件事：
> **① 机制**（跟具体字段无关）——单条件、多条件组合、清除、保存查询、无条件、空结果；
> **② 每个可过滤字段**——Redmine 有 **40+ 个可过滤字段**，**不逐条测**，而是**按字段"类型"归组、每类取一个代表**。同型字段本质行为一样（"选一个值 → 只显示匹配的"），逐条测是凑数。
>
> **那份 40 个字段的长清单，用途是"核对每类字段都碰过了"，不是用例条数来源** —— 与 F1「取值点只用于核对覆盖、不用于算通过率」同一个道理。**某个字段具体取哪个值（状态测了 Resolved 就不用再测 Closed），是测试数据的事，不是条数的事。**

**可过滤字段按类型归组**（截图里"增加过滤器"下拉的全部选项）：

| 字段类型    | 截图里的字段                          | 取几条                       |
| ------- | ------------------------------- | ------------------------- |
| 枚举下拉    | 状态 / 跟踪 / 优先级 / 指派给 / 类别 / 目标版本 | 代表：状态（F10-02）、指派给（F10-07） |
