## 三、接口层实测结果摘要

以下全部为**真实执行结果**。

### 3.1 状态码约定（实测确认）

| 场景 | 实测状态码 | 备注 |
|---|:--:|---|
| 查询 / 列表成功 | **200** | 有响应体 |
| 创建成功 | **201** | 返回新对象（含 `id`） |
| 更新 / 删除成功 | **204** | **无响应体 —— 不是 200** |
| Key 错误 / 缺失 | **401** | 响应体为空 |
| 无权限；REST API 未启用 | **403** | 响应体为空 |
| 资源不存在 | **404** | 响应体为空 |
| 字段值非法 | **422** | `{"errors":["<原因>"]}` |
| 请求体不是合法 JSON | **400** | 请求本身读不懂，不是字段值问题 |

### 3.2 边界值实测

| 字段 | 边界内 | 边界外 |
|---|---|---|
| `subject` 长度 | 255 → **201** | 256 / 300 → **422** |
| `done_ratio` | 0 / 100 → **201** | 101 / -5 → **422** |
| `estimated_hours` | 正整数 → 201 | -1 → **422** |
| `limit` | 5 → 200 | 101 → **200**（自动截断到 100）、0 → **200** |
| `offset` | 0 → 200 | -1 → **200**（容错） |

### 3.3 反直觉行为与观察项（重点）

| # | 现象 | 实测数据 | 性质 |
|:-:|---|---|---|
| 1 | **无效枚举值处理不一致** | `priority_id=999` → **422**；`status_id=999` → **201（回落 New）**；`tracker_id=999` → **201（回落 Bug）** | ⚠️ **真的不一致** |
| 2 | **无权操作的拒绝方式不统一** | 无权**改** → **204**（静默不改）；无权**删** → **403**（明确报错） | ⚠️ **真的不一致** |
| 3 | **204 不代表成功** | 非法状态转移、越权修改均返回 **204**，但数据一点没变 | ⚠️ **需特殊断言** |
| 4 | 更新 / 删除成功返回 **204** 而非 200 | REST 语义正确 | ✅ 设计如此 |
| 5 | 参数无效的处理不统一 | `limit=0` / `offset=-1` → **200**（容错）；`project_id=999` → **404**（报错） | ⚠️ 边界模糊 |
| 6 | 非法 JSON 返回 **400** 而非 422 | 400 = 请求读不懂；422 = 字段值不合法 | ✅ 设计如此 |
| 7 | 匿名可访问范围不同 | `/issues.json`、`/projects.json` → **200**；`/users.json`、`/time_entries.json` → **401** | ✅ **设计如此，不是漏洞** |
| 8 | 创建 Issue **不产生**变更记录 | 新建后 `include=journals` 为空；改 3 次 = 3 条 | ✅ 设计如此 |

> 第 1、2 条记录在 `docs/2.5-测试方案-接口用例设计.md` 第四章，**未作为缺陷提报**（属设计层面的不一致，且开源项目改动需上游评审）。
> 第 3 条直接决定了本项目的接口测试纪律：**凡 PUT / DELETE 用例，改完必须回读验证**，只看状态码会把 10 条越权用例全部误判为"通过"。

### 3.4 自动化执行

| 项 | 值 |
|---|---|
| 测试框架 | pytest + requests |
| 用例文件 | `automation/test_auth.py`、`test_issue_create.py`、`test_issue_read.py`、`test_issue_update.py`、`test_issue_delete.py`、`test_issue_list.py`、`test_scenario.py`、`test_security.py` |
| 结果 | **89 passed**（设计 87 条，参数化展开后 89 个测试） |

## 五、结论

1. **接口层** 87 条用例（展开 89 个测试）**全部通过**：认证、Issue 增删改查、过滤分页、越权控制、业务安全各项行为符合预期。

3. 记录到 **2 处接口行为不一致**，属设计层面差异，已列入观察项。
4. **界面层 69 条用例设计完成，尚未执行** —— 本报告不对界面层下通过率结论。
